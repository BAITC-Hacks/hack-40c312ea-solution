# Семь функций ассистента

## Запуск

```sh
python -m venv .venv
python -m pip install -r requirements.txt
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

Используйте Python из активированного окружения. Новая витрина: `/`, прежний инженерный интерфейс: `/engine`.
В `.env` задайте `DEMO_MODE=1` для автономного показа на шести **вымышленных** товарах. Для каталога EKT: `DEMO_MODE=0`, действующие `EKT_USER/EKT_PASSWORD`. Не коммитьте `.env`.

## Реализованный поток

Запрос RU/ҚАЗ или файл → извлечение позиций → редактируемый предпросмотр → поиск в каталоге → карточка с ценой/остатками → выбор количества и склада → серверное подтверждение на 120 секунд → повторная проверка цены и остатков → локальная корзина → необязательные дополнения.

| Функция | Реализация | Ограничение |
| --- | --- | --- |
| Менеджер | Кнопка и распознавание намерения; контакт, причина, отдельные согласия на историю/товары; предпросмотр, подтверждение, отмена | `demo_saved`: заявка хранится только в сессии. Реальная CRM/очередь менеджера не подключена |
| Разрешения | Подтверждение добавления, партии, изменения количества и удаления; цена/склад/состав привязаны к токену; отмена, TTL, защита от повторов и гонок | Нет оплаты, резервирования или создания заказа |
| Данные | Серверные случайные сессии, очистка после 30 минут бездействия, удаление с ротацией ID, маскирование типовых контактов, ограничения загрузок, CSP, проверка Origin, лимиты запросов, закрытый ручной sync | Не является аудитом всех уязвимостей или гарантией отсутствия утечек |
| Қазақша | Переключатель интерфейса, казахские шаблоны диалога, перевод ключевых слов для поиска, сохранение артикулов и чисел | Полные технические описания остаются как в каталоге; это не универсальный переводчик |
| Витрина/чат | Адаптивная витрина, карточки, плавающий чат, корзина, форма менеджера, загрузки PDF/DOCX/XLSX/XLS/CSV/JPG/PNG | Фото/сканы требуют VISION_MODEL и ключ провайдера |
| Дополнения | До трёх доступных дополнений из каталога по назначению и RECOMMEND; исключение уже добавленных; отключение предложений | Назначение не доказывает электрическую/механическую совместимость |
| Решение о покупке | Уточнение сомнений, поиск дешевле, перевод вопроса совместимости менеджеру, принятие отказа, остановка допродаж | Нет выдуманных скидок, срочности и автоматического согласия |

## API и устройство

- `app/cart_actions.py`: блокировка корзины, расчёт снимка условий, подготовка/подтверждение/отмена.
- `app/features.py`: менеджер, намерения, рекомендации, настройки сессии.
- `app/i18n.py`: RU/KK сообщения и поисковые соответствия.
- `app/security.py`: ограниченные сессии, обезличивание типовых контактов, middleware.
- `app/upload_guard.py` и `app/upload_worker.py`: проверка формата, лимиты архивов, отдельный процесс разбора без API-ключей в окружении, тайм-аут 20 секунд. Это изоляция процесса, не полноценная ОС-песочница.
- `static/store.*`: новый интерфейс. Все строки каталога/диалога вставляются через `textContent`; ссылки/фото ограничены HTTPS доменом EKT.

Основные маршруты: `/api/session`, `/api/session/language`, `/api/session/clear`, `/api/query`, `/api/catalog`, `/api/products/{id}`, `/api/recommendations/{id}`, `/api/handoff/prepare`, `/api/handoff/confirm`, `/api/handoff/cancel`, `/api/cart/prepare`, `/api/cart/confirm`, `/api/cart/prepare-batch`, `/api/cart/confirm-batch`, `/api/cart/prepare-edit`, `/api/cart/confirm-edit`, `/api/cart/cancel`, `/api/upload`, `/api/upload/confirm`.

Новый клиент сначала получает `/api/session`, затем отправляет возвращённый `X-Session-Id`. Неизвестный ID не принимается как новая выбранная клиентом сессия. Нельзя помещать ID в URL или логи. Это bearer-секрет, в браузере хранится в sessionStorage.

## Загрузка и конфиденциальность

Максимум 10 МБ, до 12 позиций на один подбор. Исходные файлы не записываются на диск. ZIP-содержимое DOCX/XLSX проверяется на размеры, обход путей, макросы и вложенные объекты. Изображения декодируются, ограничиваются 16 мегапикселями, уменьшаются, метаданные удаляются. Сканированный PDF обрабатывается только по первой странице с явным уведомлением. Текстовый PDF: до 30 страниц. Параллельно разбирается не более двух файлов.

Фото/сканы передаются настроенному ИИ-провайдеру только с `allow_external=true`. Текст запроса может передаваться провайдеру; это указано у поля ввода. Маскирование регулярными выражениями не распознаёт все персональные данные. Секретные документы загружать нельзя. Политика хранения внешнего провайдера должна согласовываться перед промышленным запуском.

Сессии и демозаявки находятся в памяти одного процесса. При перезапуске исчезают; для нескольких worker нужны общее хранилище и распределённая блокировка. Для промышленного запуска также нужны HTTPS, серверная аутентификация магазина, CRM-коннектор, мониторинг, нагрузочные проверки и проверка обработки персональных данных. Публичный `/api/sync` закрыт: требуется серверный `ADMIN_SYNC_TOKEN` в заголовке `X-Admin-Token`. Токен нельзя помещать во фронтенд. `RATE_LIMIT_PER_MINUTE` по умолчанию 180, загрузки ограничены отдельно.

## Проверки

```sh
python -m unittest discover -s tests -p test_cart_confirmation.py -v
python -m unittest discover -s tests -p test_store_features.py -v
python tests/test_agent_behavior.py
node --check static/store.js
```

Новые тесты используют синтетические товары, не вызывают платные модели и не меняют реальную корзину. Существующий QA-набор оставлен без изменения: T12 ожидает настоящую наполненную корзину EKT, которую исходный API не предоставляет; T21 использует повреждённый JPG и теперь завершается более ранней проверкой сигнатуры.

## Сценарий демонстрации

1. В DEMO_MODE открыть витрину, выбрать щит, указать 2 штуки; показать сумму 37 000 ₸ до подтверждения.
2. Отменить: корзина пуста. Повторить и подтвердить: появляются ровно две штуки.
3. Показать дополнения и кнопку отключения предложений.
4. Переключить ҚАЗ, написать «маған 900005 керек»; название/цена не меняются при переводе.
5. Написать «сатып алмаймын»: ассистент принимает отказ.
6. Открыть менеджера, показать согласия и демостатус; не заявлять об отправке человеку.
7. Загрузить `demo_spec.csv`, проверить количества, подобрать и отдельно подтвердить корзину.

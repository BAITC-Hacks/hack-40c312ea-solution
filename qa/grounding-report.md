# Достоверность, подбор и скорость — 23.09.2026

## Исправленная проблема

Запрос «мне нужны лампы для кафешки» возвращал реальные, но нерелевантные замки и коробки. API-ключ OpenAI работал; причина была в нечётком поиске без проверки назначения. Теперь назначение проверяется до и после live-detail. Светильники без ламп, патроны, драйверы, сигнальные и промышленные лампы не смешиваются с обычными лампами. Неизвестный ID не заменяется похожим товаром.

## Защита фактов

- Цена, остаток, сертификат и характеристики приходят из текущей карточки EKT. Каждая карточка имеет `source` и `verified_at`. Отсутствующее значение остаётся неизвестным.
- Изменение моделью указанных пользователем чисел, бренда и назначения отклоняется. На конфликт характеристик выводится предупреждение.
- Новый `advisor.py` использует модель для выбора релевантных кандидатов, значимых полей и уточнений по конкретной задаче. Сервер принимает только существующие ID и поля карточек. Разницу цен вычисляет код. Произвольный текст модели о цене, гарантии, доставке не показывается как факт.
- Проектирование комплекта остаётся предварительным: сгенерированные роли не считаются подтверждённой спецификацией для пакетного добавления.
- Ошибка API, неизвестный товар, отсутствие запрошенного поля, невозможность подтвердить совместимость и сбой модели сопровождаются предложением менеджера. Контакт не выдумывается, используется проверенный официальный источник.
- Неуместные запросы и распознанные попытки изменить правила не запускают подбор; платёжные реквизиты не сохраняются в истории. Это набор защит и проверок, не доказательство невозможности любой будущей ошибки или prompt injection.

## Выбор и дополнения

«Дешевле», «подороже», «в наличии» используют актуальные карточки без нового дорогого обращения к модели. Более высокая цена не называется лучшим качеством. Скорость доставки не выводится из количества товара: индивидуальный ETA неизвестен.

После подтверждённого добавления интерфейс предлагает отдельно посмотреть дополнения. Для лампы патрон предлагается только при совпадении обозначения цоколя. Назначение и необходимость объясняются; размеры и допустимая мощность требуют проверки. Нет утверждений «другие покупают вместе»: история заказов недоступна. Дополнения не добавляются автоматически, предложения можно отключить.

## Проверка общего механизма на других категориях

Проверены автоматы, кабели, распределительные щиты, розетки, контакторы и реле. Автономная матрица включает **24 сочетания: 6 категорий × 4 режима**, дополнительно к отдельным сценариям.

Живой прогон выявил общие проблемы с упоминаниями назначения: «защитный» ошибочно совпадал со «щит», кабельные аксессуары смешивались с кабелем, информационные розетки — с силовыми. Исправлены границы слов, распознавание отраслевых обозначений (ВВГ, ЩРН/ЩРВ), различение основного товара и детали «для» него. При наличии используется раздел каталога из URL EKT; разделы аксессуаров исключаются из выдачи основного оборудования. Это общие правила извлечения назначения, без списков заранее выбранных товарных ID.

Повторный живой прогон после исправления:

- Распределительный щит: корпуса ЩРН/ЩРС/ВРУ; замки, ключи и решётки исключены — **2,33 с**.
- Розетки: силовые розетки; корпуса и RJ/TEL/TV исключены — **2,39 с**.
- Контактор: реальные контакторы; готовый шкаф АВР исключён — **3,24 с**.

Это замеры повторного поиска по живому API без модели. Первичный диалог с моделью по пяти категориям занимал около 4,5–6,4 с в этом прогоне. Цена сортируется после соответствия и наличия: более дешёвый отсутствующий товар может быть ниже доступного.

Классификация и технические проверки MVP имеют ограниченное покрытие: нет утверждения о безошибочном распознавании каждой позиции каталога или полной совместимости. При недостатке сведений нужны уточнения и менеджер. Проверка назначения не заменяет проверку тока, монтажа, условий эксплуатации и паспортов оборудования.

**Метод:** реальные маршруты FastAPI вызваны через ASGI, каталог EKT заменён контролируемыми синтетическими товарами. Код приложения не менялся. GitHub, рабочая корзина EKT и платные модели не вызывались.

## Границы выводов и следующий прогон

- **Нет доступа к живому EKT API.** Один безопасный запрос чтения `GET /api/products/detail?id=515291` без учётных данных вернул HTTP 401. Синтетические ID, цены, остатки и ссылка сертификата проверяют логику, но не подтверждают актуальность реального каталога или работу ссылки на настоящий сертификат.
- **Не проверен браузерный путь до конца:** нажатия, мобильная раскладка, открытие официальной корзины и фактическое оформление. T12 следует из ответа API и явно описанного поведения проекта; состояние удалённой корзины мы не читали.
- **Не проверены платные модели и компьютерное зрение.** Токены не требовались для этого набора; расходы — $0. После настройки ключей нужен отдельный ограниченный прогон изображений, сканов и сложных запросов с фиксацией расходов.
- **Время ответа здесь не измеряет сеть EKT.** В JSON есть миллисекунды локальных сценариев; их нельзя использовать как доказательство требования «единицы секунд» на живом источнике.
- Для сравнения после доработок используйте **те же фикстуры и ID тестов**, запишите новый SHA, повторите набор и отдельно перечислите исправленные, оставшиеся и новые ошибки.

### Запуск набора после помещения в репозиторий

Поместите `test_agent_behavior.py` в `tests/` проекта, установите зависимости из `requirements.txt` и выполните `python tests/test_agent_behavior.py`. Набор сам заменяет EKT синтетическими данными и отключает вызовы моделей. Вывод — JSON; перед публикацией отчёта запишите точный SHA проверяемой версии.

# Проверка смыслового разбора — 23 сентября 2026

## Исправления

- Убрано совпадение отрицания внутри слова: «мне нужно» не считается отказом.
- Разговорные названия нормализуются для поиска и определения категории; числа, бренды и характеристики сохраняются.
- ИИ разбирает свободный выбор товара и количества по текущей подборке. Сервер проверяет IDs, типы, количество, категорию и реальные данные, затем запрашивает отдельное подтверждение.
- Названия моделей в клиентском интерфейсе не отображаются.

## Автоматические проверки

90 тестов (`python -m unittest discover -s tests -q`). Среди новых сценариев: обе исходные фразы, склонения и уменьшительные формы нескольких категорий, сохранение числовых требований, явный отказ, отсутствие побочных изменений сессии от положительного запроса, разбор пары/второй позиции, запрет вымышленных ID и неправильных количеств, проверка наличия, запрет автоматического подтверждения.

Модель не оформляет реальный заказ EKT. Корзина остаётся сессионным прототипом; демологистика явно отделена от реального наличия.

## Проверка аналога в браузере

Запрос «Есть аналог артикула 081100349_?» выявил ошибку: старый поиск возвращал отсутствующие LED светильники. Подбор исправлен: артикул в свободной фразе связывается с точным ID, альтернативы выбираются внутри назначения товара по проверяемым цоколю и мощности, цветовая температура и напряжение сравниваются, если указаны. Детали и положительный остаток перепроверяются через EKT. Без подтверждённых совпадений замена не выдумывается.
